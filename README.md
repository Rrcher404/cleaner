# 🧽 CLEANER — the game

A cute little chore game. Scrub, sort, tidy and toss — then throw the house party of the year.

## Play
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```
then visit http://localhost:8000

## How it works
- **1–4 players**, take turns on one device (pass it along!)
- **Easy / Hard / Super Hard** — less time, messier rooms, holier sponge, a chaos puppy
- **Round 1 🧽 Scrub the Wall** — your sponge has holes! Pop soap bubbles to patch them.
- **Round 2 🗑️ Pick Up the Trash** — sort it into recycle, compost and trash.
- **Round 3 🛏️ Make the Bed** — smooth the wrinkles, pull up the blanket, pillows, Teddy.
- **Round 4 🚮 Take Out the Trash** — carry the bag to the curb, hop over toys and the cat.
- **🎉 House Party** — dress up in the wardrobe, win the dance-off, get crowned.

Debug jumps: `?debug=wall|trash|bed|takeout|party&d=easy|hard|super`
